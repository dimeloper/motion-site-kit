Get started

Run it locally.
Make it yours.

The clone includes working demos and sample frames. Start the server below, then open localhost:8080. No build step or source clip is needed.

Choose your next step ↗
Terminal
git clone https://github.com/dimeloper/motion-site-kit.git
cd motion-site-kit

python3 -m http.server 8080 --directory docs
# Open http://localhost:8080
